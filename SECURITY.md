# Security policy

Security fixes are considered for the latest revision of the default branch.

Please do not disclose a suspected vulnerability in a public issue. If private
vulnerability reporting is available, use **Security → Advisories → Report a
vulnerability** on the repository. Otherwise, contact the repository owner privately
through a channel listed on their GitHub profile before sharing details publicly.
Include reproduction steps, affected versions, and potential impact. Please allow
time for investigation and a fix before public disclosure.
